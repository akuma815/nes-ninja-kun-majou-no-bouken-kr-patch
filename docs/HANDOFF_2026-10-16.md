# 최종 빌드 재현과 로컬 게임 폴더 정리 인계

2026-10-16, 한국 시간. 사용자는 “git에 최종 빌드를 위한 파일이 다 올라갔다면 게임 폴더는 삭제하자 나중에 원본롬은 내가 별도로 준비할거야”라고 요청했다. 기존 원본/후보 보존 규칙은 이 명시적 정리 요청의 범위에서 해제한다.

## 재빌드 검증

- 공개 저장소를 새 디렉터리에 직접 복제했다. 이전 로컬 게임 폴더에서 빌드 파일이나 자산을 복사하지 않았다. 원본 ROM 경로만 `-SourceRom`으로 외부 주입했다.
- 검증한 소스 커밋: `bac24b0c77fcc28ce2f661b6fd8eec03541a37e2` (v1.0 태그). Python 3.12.10 / Pillow 12.3.0, Windows PowerShell 빌드 진입점으로 성공했다.
- 입력: iNES 헤더 포함 24,592바이트, SHA-256 `7d4e1f61f8f7464d73a35c5118f59227dd7d7ddd6c3c2a62e42f5a0ac9477978`.
- 출력: 49,168바이트, SHA-256 `325109b789525c781cb72e78392768df8625fd55c04f78f329ece540993cf51d`.
- BPS: 1,548바이트, SHA-256 `de06bb9d99b37a76ea7dc92a71fed1fc324bbc1668ba7aa5748734c3d839d2a0`.
- 최종 ROM/BPS가 정식 v1.0과 동일하다. 스크립트·원본 식별/타일/훅 설정·채택한 NES 로고 PNG·의존성 명세 등 최종 빌드 필수 파일이 Git에 있다. 생성 원본 이미지와 로컬 분석 덤프는 최종 빌드의 입력이 아니다.
- 검증 원장은 [rebuild_verification_2026-10-16.json](rebuild_verification_2026-10-16.json). 이번 세션의 증거는 빌드·BPS 재현이며 새 게임 플레이/완주 검증을 뜻하지 않는다.

## 정리 상태

- 삭제 대상은 `Games/Ninja-kun - Majou no Bouken` 디렉터리 하나다. 다른 게임·사이트·공개 릴리즈는 삭제 대상이 아니다.
- 삭제 전 지원 원본으로 재현 검증, 원격 Git 인계 반영, 별도 작업 기록 ZIP의 파일별 SHA-256 검증을 완료한 뒤 진행한다.
- 원본/완성 ROM, 원본 추출, RAM/PPU 덤프, 개발용 IPS, 도구/의존성 실행 파일은 별도 작업 기록 백업에 넣지 않는다. 사용자가 원본 ROM을 별도로 준비한다.
- 정리 전 집계: 1,212파일·814,086,148바이트, 대상과 하위 경로의 재분석 지점 0개.
- 실제 삭제 완료 결과와 백업 정보는 삭제 후 이 문서에 기록한다.

## 복원과 빌드

```powershell
git clone https://github.com/akuma815/nes-ninja-kun-majou-no-bouken-kr-patch.git
Set-Location nes-ninja-kun-majou-no-bouken-kr-patch
python -m pip install -r requirements.txt
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -SourceRom '별도로 준비한 지원 원본.nes'
```

ROM은 Git에 없으며 직접 준비한다. 입력 해시가 다르면 빌드가 거부된다. 결과는 `build/title_kr_release_100/Ninja_kun_Majou_no_Bouken_KR_title_release_100.nes`, 공개용 BPS는 `patches/Ninja_kun_Majou_no_Bouken_KR_title_release_100.bps`다. 개발용 IPS는 로컬 진단 산출물이며 공개하지 않는다.

## 배포와 확인 범위

- [v1.0 릴리즈](https://github.com/akuma815/nes-ninja-kun-majou-no-bouken-kr-patch/releases/tag/v1.0), ZIP SHA-256 `54ff12ce7e0df5689ca9c8c0885a1f8d9b6528ab21fca8cbbf996c335957a606`. [페이지](https://akuma815.github.io/)에 실제 타이틀 캡처와 링크가 있다.
- 타이틀 로고 `忍者くん` → `닌자군`만 번역하고 영문을 유지한다. 타이틀 외 일본어를 발견하지 못했다는 사용자 플레이 보고는 별도 근거이며, 에이전트의 전체 완주 판정으로 확대하지 않는다.
- 기존 Mesen2.1.1 부팅/시작/리셋, 로고 밖·비타이틀 픽셀 비교, 실제 Windows 적용과 독립 BPS 적용을 완료했다. 이번 재빌드의 동일 해시는 기존 게임 바이트와의 연결 근거다.
- 출력은 원본 매퍼0에서 CNROM 매퍼3/PRG32KiB/CHR16KiB로 확장됐다. 원래 NROM 카트리지 회로와 다르며 원본 ROM용 세이브스테이트 대신 새로 부팅한다. 에이전트의 전체 완주·모든 후반 씬·실기·다른 에뮬레이터·오디오 청취는 미수행이다.
