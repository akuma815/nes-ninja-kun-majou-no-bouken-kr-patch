# 닌자군 - 마성의 모험 한글 패치 v1.0

사용자는 2026-10-16에 **타이틀만 번역한 현재 결과를 정식 v1.0으로 공개 배포하고 실제 타이틀 캡처와 함께 아카이브 페이지에 추가**하도록 명시적으로 요청했다. 이 결정으로 이전 개발 시험판/미관 승인 대기 상태를 타이틀 범위에 한해 해제한다.

사용자 플레이 보고: **“실제 플레이시 그 외 일본어는 발견하지 못했어”**. 이는 사용자의 직접 플레이 확인이며, 에이전트의 완주·실기 검증이나 사용자가 원본/결과 해시까지 별도 측정했다는 의미로 확대하지 않는다.

- 범위: `忍者くん` → `닌자군` 타이틀 로고만. 영문 메뉴·HUD·시작·게임 오버·보너스는 유지한다.
- 릴리즈 빌드: `title_kr_release_100`. 게임 바이트는 검증된 002와 동일하다.
- 원본: 24,592바이트, SHA-256 `7d4e1f61f8f7464d73a35c5118f59227dd7d7ddd6c3c2a62e42f5a0ac9477978`.
- 결과: 49,168바이트, SHA-256 `325109b789525c781cb72e78392768df8625fd55c04f78f329ece540993cf51d`.
- 배포 형식: 원본 참조 BPS. 확장용 원본 PRG/CHR 복제 데이터는 패치 리터럴로 통째로 싣지 않고 원본에서 복사한다. BPS 원본/결과/패치 CRC와 Windows 적용 도구의 SHA-256을 함께 검사한다. 개발용 IPS는 로컬 보존만 한다.
- 출력 구조: CNROM 매퍼3, PRG32KiB/CHR16KiB. 원래 NROM 실기 회로 호환성으로 주장하지 않는다. 새 ROM을 콜드 부팅하며 원본용 세이브스테이트는 사용하지 않는다.
- 검증 등급: 빌드·무결성·실제 Windows 적용·독립 BPS 적용·공개 첨부 검증은 별도 기록한다. 런타임은 Mesen2.1.1 부팅/시작/리셋, 타이틀6장 바깥 차이0 및 비타이틀4장 전체 차이0이다. 사용자 보고와 앞선 원본-ROM 일문 조사는 별도 근거다.
- 에이전트 전체 완주·모든 후반 씬·실기·다른 에뮬레이터·오디오 청취는 미수행이다. 숨은 모든 메시지를 배제한 완전 번역이라고 표현하지 않는다.
